# PDF 编辑器（阶段一：页面管理 · 阶段二：矢量文字编辑 · 阶段三：扫描件）

按《PDF编辑软件技术要求说明书》开发的桌面端 PDF 工具。Python + PySide6 + PyMuPDF，全部离线、纯 CPU 运行。

## 安装

需要 Windows 10/11 与 conda（或任意 Python 3.11）。在项目目录内创建环境并安装依赖：

```
conda create -p ./venv python=3.11 -y
venv\python.exe -m pip install -r requirements.txt
```

文字编辑使用系统自带字体（宋体、黑体等，位于 `C:\Windows\Fonts`）。

## 启动

双击 `run.bat`，或：

```
venv\python.exe -m pdfedit [要打开的文件...]
```

运行测试：

```
venv\python.exe -m pytest tests
```

测试样本由测试代码自动生成；少数用例需要样例文件《PDF编辑软件技术要求说明书.pdf》（未随仓库提供），缺少时自动跳过。

## 目录结构（对应说明书第 3 节四层架构）

```
pdfedit/
  core/      核心引擎层：所有 PyMuPDF 读写都在这里
    engine.py    源文件管理（只读打开、密码、自动修复、图片转 PDF）
    pagetype.py  页面类型自动识别（3.2 节规则，阈值集中在 THRESHOLDS）
    render.py    几何换算、DisplayList 缓存、分块局部渲染
    writer.py    合并 / 拆分 / 图片导出、区域页生成、临时文件原子写入
    naming.py    批量导出命名模板
    fonts.py     系统字体扫描（解析字体 name 表）与 7.3 字体选择规则
    textedit.py  文字块提取、真删除（redaction）、排版写入（字体子集）、查找替换
    scan.py      扫描图像：主图读写、纠偏 / 去黑边 / 去噪 / 增强 / 二值化、擦除（保留表格线）
    ocr.py       OCR（RapidOCR，纯 CPU）与逐字定位的透明文字层
    scanedit.py  覆盖式编辑：字号 / 墨色 / 宋黑仿楷估算、擦除原字、矢量或渲染进图片重写
  app/       应用逻辑层（不依赖界面，可单独测试）
    workspace.py 工作区页面列表 + 撤销重做（整表快照，100 步）
    exporter.py  各种导出模式
    regions.py   区域选区
    textservice.py 文字编辑服务：写时复制页面版本（撤销重做覆盖文字编辑）、权限密码
    scanservice.py 扫描服务：OCR 升级（不占撤销历史）、预处理、区域擦除、恢复原始页面
    project.py   项目文件、自动保存、崩溃恢复
  ui/        用户界面层
    main_window.py  主窗口与全部操作入口
    viewer.py       主视图（连续/单页、10%–6400% 缩放、分块高清渲染、选区绘制与调整）
    textlayer.py    主视图的文字编辑交互（文字块框、选中/拖动/删除、就地编辑框）
    thumbs.py       缩略图（拖拽排序、插入指示线、来源色条、类型角标、懒加载）
    panels.py       书签 / 文字属性 / 区域选取 / 查找替换面板
    dialogs.py      导出对话框、后台任务进度
    render_service.py 后台渲染与识别线程
    ocr_worker.py   后台 OCR 队列（进度、取消）
tests/       自动化测试（含 5.4 节页面顺序验收规则）
```

OCR 不改变页面外观，因此不进入撤销历史：识别结果会同步到历史中的该页，撤销其他操作不会丢失识别结果。
扫描页上的查找替换同样走“擦除 + 原位重写”。

性能实测（1000 页文字 PDF，本机）：打开 0.2 s，翻页 0.1–0.14 s，拖拽 100 页 0.1 s，导出 500 页 0.5 s，内存约 200 MB。

## 已知限制

- 文字编辑按“块”整块重写：一个块内若混有多种字体/颜色，编辑后统一为首个字符的样式；替换时受影响的行整行重写。
- 原文件中文常为 Type3 或无 Unicode 映射的子集字体（如浏览器打印的 PDF），无法复用，会回退到系统同名字体或默认宋体，外观可能与原文略有差异（界面会提示）。
- 被裁剪路径部分遮挡的文字，编辑后新文字不再受原裁剪限制。
- 竖排（wmode=1）文字的重写位置为近似计算，建议用真实样本复核。
- 扫描件的测试样本是由矢量页面模拟生成的（倾斜、噪点、模糊、灰底、JPEG、红章），尚未用真实扫描件验证；
  印章压字处 OCR 会出错，覆盖式修改近看可分辨痕迹（技术要求 8.4）。
- 未纠偏的倾斜扫描页上，重写的新文字是水平的；建议先「图像预处理 → 自动纠偏」再修改。
- OCR 速度：300 DPI A4 约 3–5 秒 / 页（首页含模型加载）。
- 导出时选择“统一缩放到某纸张”，页面会重新排版放置，原批注和链接不会保留（界面有提示）。
- 多边形 / 手绘选区开启“彻底移除选区外内容”时，外接矩形以外的内容会被真正删除；外接矩形以内、多边形以外的内容只是被裁剪隐藏。
- 页面类型识别的阈值尚未在真实样本库上调优，识别有误时可在右键菜单中手动更正。
- 未使用 qpdf 做结构校验（qpdf 未安装）。
